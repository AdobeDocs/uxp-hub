# navigator

## language : `string`

**Read only**

**Since**: v8.0

UXP supports the [Navigator.language](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/language) property.

```js
const language = navigator.language;
console.log(language);
```

For clipboard operations, see [navigator.clipboard](../data-transfers/clipboard.md).
